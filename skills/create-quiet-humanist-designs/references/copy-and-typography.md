# Copy and Typography Contract

## Copy first

Before making imagery, prepare a small copy deck:

| Role | Requirement |
|---|---|
| Headline | One clear idea; usually 2–8 words |
| Support | One sentence that explains function, consequence, or invitation |
| Metadata | Date, place, price, edition, feature number, source, or status when relevant |
| Destination | Brand, URL, handle, or contact |
| CTA | One concrete action when the medium needs it |

If the user provides only a feature name, write a natural support line. Avoid inflated claims, generic “unlock,” “revolutionize,” “future,” and AI-flavored filler.

## Tone

- Prefer observed language over advertising language.
- Let one concrete verb carry the sentence.
- Keep functional copy plain enough to understand without the image.
- Use poetic language only when it clarifies mood or metaphor.
- Preserve the user's language and register.

## Typesetting

- Use no more than two type families or two visibly distinct modes.
- Create hierarchy through scale, width, spacing, case, and position before adding effects.
- Make the headline easy to locate. It may lead or co-lead with the focal drawing according to the medium and reference grammar.
- Keep factual copy stable and legible even when display type behaves expressively.
- Do not generate essential text inside raster imagery.
- Re-type exact words after image generation and proofread character by character.
- Check punctuation, URL, dates, units, and line breaks.
- Assemble the final type over or around the completed illustration using a deterministic layout tool. Do not treat the copy deck as a substitute for the typeset artifact.
- Re-create hand-set feeling deterministically through selective letter spacing, baseline shifts, word-scale changes, rotation, stamping, or outline irregularity. Keep the exact character sequence inspectable.
- Do not default to condensed grotesk plus monospaced support copy. Choose the type relationship from the concept and reference grammar.

## Medium rules

### Poster and social

- Typeset headline, support, metadata, and destination into the final artifact.
- Create one intentional relationship between type and image: counterweight, overlap, carry, point, reveal, measure, transform, or frame.
- Keep critical copy within the central safe area.
- Check at feed thumbnail size.
- Preserve SVG, layout code, or editable design source when practical.

### Email

- Keep heading, body, CTA, deadline, price, and accessibility information as live HTML.
- Use the visual as atmosphere, not the sole carrier of meaning.
- Supply alt text for meaningful imagery.

### Presentation

- Keep titles, body copy, labels, footnotes, and data editable.
- Use display treatment on title, section, quote, and closing slides.
- Use a quieter type system on content and data slides.

### Frontend and web

- Use semantic HTML for headings, paragraphs, navigation, and actions.
- Preserve logical reading order and keyboard access.
- Meet accessible contrast; do not place small copy over active texture.
- Create desktop and mobile crop plans.
- Keep decorative lettering separate from functional UI text.

### Cover and invitation

- Prioritize title, author or host, date, place, and action.
- Small editorial type may be intimate, but factual details must remain readable.

## Final copy QA

- No placeholder text.
- No generated gibberish.
- No missing feature explanation.
- No inaccessible text baked into imagery when live text is possible.
- No line break that changes meaning.
- No decorative treatment that hides a required word.
